# アルクバコ（Arukubako）v0.2 ゲーム仕様書

## 1. コンセプトと基本情報
- **タイトル**: アルクバコ（Arukubako）
- **ジャンル**: 位置情報連動 3D ボクセル・トイブロック建築ゲーム
- **対象プラットフォーム**: Android（Capacitor 8） / Web ブラウザ（検証・室内テスト対応）
- **パッケージID**: `com.arukubako.app`
- **ビジュアル方針**: テクスチャを使用しない完全な単色直方体ブロック＋頂点アンビエントオクルージョン（Voxel AO）＋ビビッド・トイブロック調 UI（濃紺枠線 `2.5px`＋ハードシャドウ）

---

## 2. 地理座標・区画・当たり判定仕様

### 2.1 区画グリッドと解像度
- **区画サイズ**: Web Mercator 空間上で赤道換算 `30m` 四方（日本付近・緯度 35°N 前後では約 `24.4m × 24.4m`）
- **1区画のボクセル解像度**: `12 × 48 × 12`（横 `12` × 高さ `48` × 奥行 `12`）
  - 1ブロックの大きさ：約 `2.03m` 立方
  - **建築高さ上限**: `Y = 0 〜 47`（高さ `48` 段 ≈ 約 `96m`、30階建てビル級）
- **隣接連結性**: Web Mercator 空間上で水平・垂直が同一スケールを共有するため、隣り合う区画の端同士は歪みや隙間なく連続する。

### 2.2 探索解放の当たり判定（円 × 区画矩形交差）
- **探索半径**: プレイヤー周囲半径 `40m`
- **判定式**: プレイヤー位置 `(lng, lat)` から各区画の矩形領域 `[minLng..maxLng, minLat..maxLat]` 上の最近接点までの Haversine 距離 `distanceFromPointToPlotMeters <= 40m`
- **特徴**: 探索円が区画の「辺」または「角」に少しでも重なれば即座に解放される（区画中心まで入る必要がない）。未解放区画カードにも「区画端までの残り距離」が表示される。

## 3. 現実地形・実標高傾斜・バイオーム自動生成

### 3.1 実標高（DEM）取得とフォールバック
- **取得元**: AWS Open Data Terrarium PNG タイル（`z = 14`, CORS対応, APIキー不要）
- **デコード式**: `Elevation(m) = (R × 256 + G + B / 256) - 32768`
- **オフライン／未読込時フォールバック**: 決定論的地形生成関数（`高尾山・山麓斜面` 周辺には急斜面を内蔵）で動作し、実タイル読込完了後に非同期で地形とバイオームを自動更新する。

### 3.2 バイオーム分類と地図カラー・自動生成地形・地図3D標高連携
地図描画時は OpenFreeMap（OpenStreetMap系ベクタータイル）の重い 3D 建物押し出しを非表示にし、代わりに **AWS Terrarium DEM による MapLibre 3D地形起伏＋ヒルシェード** と **各解放区画の実際のボクセル地形＋基礎スカート** を標高同期して描画する。

| バイオーム | 地図上の色 | 判定条件（優先度） | 集まりやすい素材 | 自動生成される地形ブロック |
|---|---|---|---|---|
| **公園・緑地 (`park`)** | `#10B981`（緑） | 公園・森林・緑地地物 | ウッド55% / クレイ25% | 緑の草地＋小道＋ボクセルの木 |
| **水辺・河川 (`water`)** | `#0EA5E9`（水色） | 川・湖・海地物 | クレイ52% / グロウ10% | 砂底＋半透明ガラスの水面＋緑の岸辺 |
| **市街地・駅前 (`urban`)** | `#6366F1`（藍） | 商業地・建物密集・幹線道路 | ストーン56% / クレイ20% | グレー舗装＋低層の都市建築基礎・植え込み |
| **住宅街 (`residential`)** | `#F97316`（橙） | 住宅地・生活道路 | ウッド34% / ストーン34% | 小道＋ライムの生垣＋カラフルな花 |
| **山・斜面 (`mountain`)** | `#8B5CF6`（紫） | 標高 `80m` 以上かつ高低差 `3.0m` 以上、または標高 `140m` 以上 / 高低差 `10m` 以上 | ストーン44% / ウッド32% / グロウ10% | 実標高に基づく岩肌の坂・崖＋松の木 |
| **街角エリア (`open`)** | `#14B8A6`（青緑） | 上記以外の平地 | 4素材バランス型 | 草原と点在する花ブロック |

- **8方位の標高連続性**: 建築画面では、中心区画の前後左右・斜め 8 方位の隣接区画を `(隣接区画の最低標高 - 中心区画の最低標高) / 1ブロックm` だけ上下オフセットして同時描画するため、山斜面や隣接建築がシームレスに繋がる。
- **地形の掘削と整地**: 自動生成された地形ブロックは「壊す」ツールで自由に削ってトンネル・地下・整地が可能（自動生成ブロックを壊しても手持ちブロックには戻らない）。「地形復元」ボタンで削った地形を戻せる。

## 4. 収集・クラフト・ブロック体系

### 4.1 収集ループ（ハイブリッド型）
1. **歩行自動収集**: 25m 歩くごとに現在地のバイオームに応じた重み付けで素材を 2〜3 個自動獲得。
2. **レア採集スポット（マップピン）**: 約 75m 間隔のグリッド（周囲 220m 圏内）に高確率で出現し、各スポットの実座標にティアドロップ型マップピンとして表示（メートル数値表示を省いたすっきり表示）。半径 50m 以内に入るとピンが黄金枠で脈動し、タップで大量採集可能（再湧き 15 分、仮想歩行時は遠いピンをタップして自動移動も可能）。

### 4.2 素材4種 → 3系統クラフト → 全19色ブロック
- **生素材（4種）**: `ウッド` / `ストーン` / `クレイ` / `グロウ`
- **クラフト在庫（3系統）**:
  - **ソリッド (`solid`)**: ウッド×1→6、ストーン×1→6、クレイ×1→6、3種×1まとめ成形→24
  - **ガラス (`glass`)**: クレイ×1＋グロウ×1→6
  - **ライト (`light`)**: グロウ×1→4
- **建築パレット（19色）**:
  - ソリッド 16 色（レッド、オレンジ、イエロー、ライム、グリーン、ターコイズ、スカイ、ブルー、インディゴ、パープル、ピンク、ブラウン、サンド、ホワイト、グレー、ブラック）
  - 半透明ガラス 1 色（クリアガラス）
  - 夜間発光ライト 2 色（ウォームライト、シアンライト）
- **初期所持数**: 素材 `ウッド6 / ストーン6 / クレイ5 / グロウ3`、在庫 `ソリッド80 / ガラス12 / ライト6`
- **破壊返却ルール**: プレイヤーが自分で設置したブロックを壊すと、対応系統の在庫へ 100% 返却される。

## 5. 実績・建築ツール・設計図プリセット

  - アイソメトリック簡易プレビュー画像＋`ソリッド / ガラス / ライト` の必要/所持数を表示
  - 配置時は 3D 半透明ホログラムプレビューが表示され、「90°回転」「配置確定」「キャンセル」が可能

## 6. 地図パフォーマンス＆3段階ズームLOD仕様
- **近景 (`Zoom >= 15.2`)**: 画面表示領域内の解放区画（最大 64 区画・LRU キャッシュ 80 件）を 3D ボクセル描画
- **中景 (`12.0 <= Zoom < 15.2`)**: 3D メッシュ描画をスキップし、ビューポート内区画のバイオーム別 2D 色分けポリゴンのみ表示
- **広域 (`Zoom < 12.0`)**: 個別区画を非表示にし、クラスタリングされた開拓件数バッジのみ表示
- **建築エディタ**: カメラ操作・編集・ポインター移動時のみ再描画するオンデマンド描画方式を採用

## 7. セーブデータ永続化（Schema v2）
- IndexedDB（`arukubako-db`）＋ `localStorage` フォールバック＋JSON エクスポート／インポート
