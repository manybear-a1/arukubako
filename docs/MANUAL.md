# アルクバコ（Arukubako）v0.2 操作手順書・評価ガイド

## 1. 起動・検証環境セットアップ

### ブラウザでのテスト起動（PC / モバイルエミュレーション）
```bash
npm install
npm run dev
```
ブラウザで表示される URL（通常 `http://127.0.0.1:5173`）を開きます。Chrome DevTools などでモバイル縦画面（例 `390×844`）に切り替えるとスマホ実機に近いレイアウトで操作できます。

### Android 実機ビルド手順
```bash
npm run cap:sync
npx cap open android
```
Android Studio で `android/` プロジェクトを開き、Gradle 同期後に実機またはエミュレータで **Run (▶)** を実行してください。

## 2. 画面別・基本操作ガイド

### A. メインマップ画面（探索・採集）
1. **上部のステータスバー**:
   - 左上に現在のバイオームバッジ（色分け）、累計歩行距離、次の自動採集（25mごと）までのゲージが表示されます。
   - 右上の 3 つのボタンで左から **「バイオーム凡例表示」**、**「昼／夕方／夜の時間帯切替」**、**「仮想歩行／GPS モード切替」** が行えます。
2. **レア採集スポット（マップ上のピン）**:
   - 地図上のスポット位置にカラフルなマップピンが表示されます（画面の情報量を抑えるため距離数値は表示されません）。
   - 半径 50m 以内に入るとピンが黄色く光って弾み、タップすると大量の素材（`グロウ` 含む）を採集できます。
   - 仮想歩行モード時は、離れたピンをタップするとその場所へ向かって自動で歩き始めます。
3. **仮想歩行コントローラー（右下・仮想歩行時のみ表示）**:
   - 十字キーで前後左右へ移動します（長押しで連続歩行）。
   - **「徒歩 / 早歩き」** で移動速度を切り替えられます。
   - **「移動」** メニューから代表的な検証スポットへ一瞬でワープできます：
     - **代々木公園**（公園・緑地）
     - **高尾山・山麓斜面**（**急傾斜の山の地形**をすぐ体験可能）
     - **東京駅・丸の内**（市街地・舗装と基礎）
     - **京都・鴨川**（水辺・河川）
     - **浅草・下町**（住宅街）
4. **区画の解放と建築開始**:
   - プレイヤー周囲の破線円（半径 40m）が区画の端・角に少しでも触れると、その区画が自動で解放されバイオーム色と 3D 地形ブロックが生成されます。
   - 解放済み区画をタップして下部のカードを開き、**「この区画に建築する」** を押すと 3D 建築画面へ移ります。
5. **広域表示（縮尺LOD）**:
   - 地図をピンチ／ホイールで引いていくと、中距離で軽量な 2D バイオーム表示になり、さらに引くと開拓エリアの件数クラスターバッジへ自動的に切り替わります。

### B. 3D 建築エディタ画面（12 × 48 × 12）
1. **カメラ操作**:
   - **1本指ドラッグ（左ドラッグ）**: 視点の回転
   - **ピンチ（マウスホイール）**: ズームイン／アウト
   - **2本指ドラッグ（右ドラッグ）**: 視点の平行移動
   - 周囲 8 方位（前後左右＋斜め）の隣接区画の傾斜や既存建築も薄めのトーンで同時に表示され、区画の境界には **N / E / S / W** 方位マークが表示されます。
2. **ブロックの設置と破壊**:
   - 下部パレットから **全 19 色**（ソリッド 16 色＋ガラス＋ライト 2 色）を選択します。
   - 地面・既存ブロックの面を短タップするとブロックを配置します。
   - **「壊す」** モードで自分が置いたブロックを壊すと在庫へ 100% 返却されます。自動生成された山の斜面や木を削ることも可能です（在庫返却はされませんが **「地形復元」** ボタンで元の地形へ戻せます）。
3. **高さガイド（右側パネル `Y = 0 〜 47`）**:
   - スライダーまたは `＋` / `－` ボタンで編集高度を切り替えられます。指定した高さに青い補助グリッドが表示され、足場なしで高層建築や空中配置が可能です。
4. **設計図スタンプ（5区画解放でアンロック）**:
   - ツールから **「設計図」** を選ぶと、簡易プレビュー付きカードと `固 / 硝 / 灯` の必要数・所持数が表示されます。
   - 設計図を選んで区画内の任意の場所をタップすると **3D 半透明プレビュー** が出現し、**「90°回転」** や位置微調整をしてから **「配置確定」** で建築できます。
5. **保存**:
   - 右上の **「保存して地図へ」** を押すと変更が保存され、即座に 3D 地図上へ反映されます。

## 3. v0.2 評価チェックリスト（テスト手順）

以下の順で操作すると、v0.2 のすべての改善ポイントを確認できます：

1. **UI・視認性確認**: メイン画面のトグルで凡例を開き、6 つのバイオーム色とトイブロック調 UI（枠線・シャドウ）を見やすさ観点で確認する。
2. **区画端判定の確認**: 仮想歩行でゆっくり歩き、探索円の端が隣の未解放区画の辺に触れた瞬間に解放されることを確認する。
3. **レアスポットピン確認**: 地図上のカラフルなピンを確認し、仮想歩行で離れたピンをタップして近づいた後、黄色の光るピンをタップして素材とグロウが入手できることを確認する。
4. **実標高3D地形＆8方位確認**: 「移動」→「高尾山・山麓斜面」を選び、地図自体の山起伏にボクセル斜面地形が浮かずに接地して描画されることを確認 → 建築画面を開き、視点回転が滑らかに動くこと、周囲 8 方位の斜面が連続していること、高さ `Y = 30` 以上まで積めることを確認する。
5. **地形掘削＆19色＆設計図確認**: 地形ブロックを 1 つ壊してから「地形復元」で戻ることを確認し、19 色パレットでカラフルなブロックを配置 →（5区画以上解放状態で）設計図のプレビュー表示・3D ホログラム・90°回転・配置確定を確認する。
6. **軽量化・LOD確認**: 地図に戻り、ズームアウトして 3D → 2D → クラスターバッジへ切り替わること、およびページリロード後も全データが残っていることを確認する。
